# AI 销售陪练 · 产品原型文档 v1.0

## 1. 产品概述
面向销售人员的 AI 对话陪练产品。用户选择场景（电话销售、客户主动咨询、成交谈判、地推破冰），与 AI 角色进行语音/文字对练，练后获得多维度评估，并通过能力看板持续针对短板训练。

## 2. 视觉风格
| 项 | 规范 |
|---|---|
| 背景 | 浅暖白 `#FAF7F5`，卡片纯白 `#FFFFFF` |
| 主色 | 珊瑚红 `#FF6F61`（悬停 `#F2564A`，浅底 `#FFE9E6`） |
| 辅助色 | 墨灰文字 `#2B2B2B`、次要文字 `#8A8580`、成功 `#2FB67C`、警示 `#F5A623` |
| 圆角 | 卡片 16px，按钮 999px（胶囊） |
| 字体 | 中文 PingFang SC / 思源黑体；数字 DIN 风格 |
| 风格差异 | 区别于小红书：主色偏橙的珊瑚红而非正红；卡片带场景类别色条与人物头像；留白更多、阴影更柔 |

场景类别标签色：电话销售 珊瑚红 / 客户主动咨询 青绿 / 成交谈判 琥珀 / 地推破冰 天蓝。

## 3. 信息架构
```text
应用
├── 首页（场景列表）
│   └── 场景详情 → 练习页面 / 通话页面 → 练后评估
├── 构建（场景构建及修改）
├── 看板（能力仪表盘）→ 专项训练 → 推荐场景
├── 我的
│   ├── 练习记录 → 评估详情 / 回放
│   ├── 设置
│   └── 关于
└── 登录 / 注册（未登录时拦截）
```

## 5. 页面原型

### 5.1 首页（场景列表）
```text
PC：
+--------------------------------------------------------+
| 为你推荐   [全部][电话销售][客户咨询][成交谈判][地推破冰]|
+--------------------------------------------------------+
| +----------+ +----------+ +----------+ +----------+    |
| | 封面图   | | 封面图   | | 封面图   | | 封面图   |    |  瀑布流
| |[电话销售]| |[成交谈判]| |✓已练习 3次| |          |   |  4列
| | 标题     | | 标题     | | 标题     | | 标题     |    |
| | 描述两行 | | 描述两行 | | 描述两行 | | 描述两行 |    |
| |头像 角色 | |头像 角色 | |头像 角色 | |头像 角色 |    |
| |难度★★★ | |   85分   | |  最高82分| |          |    |
| +----------+ +----------+ +----------+ +----------+    |
+--------------------------------------------------------+
手机：双列瀑布流，类别筛选横向滚动。
```
- 卡片元素：封面图、类别标签、标题、描述（≤2 行）、人物头像+名称+身份（如“王总·采购总监·谨慎型”）、难度、时长。
- 已练习：右上角角标“已练习 N 次”+ 最高分。
- 点击卡片 → 场景详情弹层（底部抽屉/PC 侧弹窗）：目标、人物画像、评估要点，按钮【开始对练】【电话模式】。

### 5.2 练习页面（参考 Yoodli）
```text
PC：
+--------------------------------------------------------+
| ← 退出   场景：首次电话邀约          ⏱ 03:24   ⚙ 设置 |
+----------------------+---------------------------------+
| 参与者               |  提示画面屏                     |
| [AI 头像] 王总       |  ┌───────────────────────────┐  |
|  采购总监·谨慎型     |  │ 🟢 轮到你说话了            │  |
|  ●●● 思考中          |  │ 提示：先确认对方痛点，再   │  |
|                      |  │ 引出产品价值               │  |
| [我的头像] 我        |  └───────────────────────────┘  |
|  🎤 正在聆听          |  教练：对方语气犹豫，建议...  |
+----------------------+---------------------------------+
| 对话记录                                               |
|  王总：我们现在已经有供应商了。                        |
|                         我：理解，方便问下您目前...    |
+--------------------------------------------------------+
| [⏮回放] [⏸暂停/▶继续] [ 🎤 按住说话 ] [⏹停止] [⌨文本] |
+--------------------------------------------------------+
手机：顶部参与者横条 → 提示屏 → 对话气泡（可滚动）→ 底部操作栏。
```
- 提示屏状态：等待开始 / 对方思考中 / 对方说话中 / 轮到你说话 / 回答提示 / 教练点评 / 已暂停。
- 默认语音输入，实时转写显示；点⌨切换文本输入框。
- 设置：语速、提示开关、教练模式开关、音色。

### 5.6 我的
- 头部：头像、昵称、等级、总练习次数。
- 入口：练习记录、我构建的场景、设置、关于、退出登录。

### 5.7 练习记录
列表项：场景封面缩略、标题、类别、日期、时长、得分、模式（对话/通话）；筛选（类别、时间、分数）；点击 → 评估详情，支持回放、再练。

### 5.8 构建（场景构建及修改）
```text
+---------------------------+----------------------------+
| 步骤：①基础 ②目标 ③角色 ④参数 ⑤预览                   |
+---------------------------+----------------------------+
| 基础：名称、类别、封面、描述、难度                     |
| 目标：练习目标、成功标准、评估维度权重                 |
| 角色画像：姓名、职位、公司、性格、态度、痛点、         |
|           常见异议、隐藏信息                           |
| 参数：语速(0.8–1.5x)、音色、开场方、时长上限、提示强度 |
| 预览：右侧实时卡片预览 + [试练] [保存草稿] [发布]      |
+---------------------------+----------------------------+
```
手机端为分步表单，底部“下一步”。列表页展示“我的场景”，支持编辑/复制/删除。

### 5.9 设置 / 关于 / 登录注册
- 设置：账号信息、默认输入方式、麦克风测试、默认语速、提示与教练开关、通知、隐私、清除缓存。
- 关于：版本号、产品介绍、用户协议、隐私政策、反馈。
- 登录注册：手机号+验证码 / 邮箱+密码，第三方登录；首次登录引导选择岗位与目标能力（用于个性化推荐）。

## 6. 核心流程
```text
登录 → 首页推荐 → 选场景 → 选模式(对话/通话) → 对练 → 停止/挂断
     → 练后评估 → (再练 | 看板 → 专项训练 → 推荐场景)
```
