# AI 销售陪练 · 产品规格说明书 v1.0

## 1. 范围与术语
- 场景：一次练习的设定，含类别、目标、AI 角色画像、参数。
- 会话：用户针对某场景的一次练习（对话模式或通话模式）。
- 评估：会话结束后生成的阶段 / 维度 / 状态得分与建议。

## 2. 响应式规范
| 断点 | 宽度 | 导航 | 首页列数 |
|---|---|---|---|
| 手机 | <768px | 底部 4 Tab（首页/构建/看板/我的） | 2 |
| 平板 | 768–1023px | 底部 Tab | 3 |
| PC | ≥1024px | 左侧菜单（首页/构建/看板/我的▸练习记录、设置） | 4（≥1440 为 5） |

- 练习/通话页为全屏沉浸，手机端隐藏底部 Tab。
- 触控目标 ≥44px；PC 支持快捷键：空格=按住说话，P=暂停/继续，Esc=停止。

## 3. 功能需求

### 3.1 首页（场景列表）
| 编号 | 需求 | 优先级 |
|---|---|---|
| H-01 | 按用户岗位、短板能力、历史练习个性化排序推荐场景 | P0 |
| H-02 | 图文卡片瀑布流，展示封面、类别、标题、描述、人物、难度、时长 | P0 |
| H-03 | 类别筛选：全部/电话销售/客户主动咨询/成交谈判/地推破冰 | P0 |
| H-04 | 已练习卡片标注“已练习 N 次”及最高分 | P0 |
| H-05 | 搜索场景名称/人物 | P1 |
| H-06 | 下拉刷新、无限滚动（每页 20） | P1 |

### 3.2 练习页面
| 编号 | 需求 | 优先级 |
|---|---|---|
| P-01 | 参与者模块：AI 角色与用户头像、名称、实时状态 | P0 |
| P-02 | 提示画面屏：状态（思考中/说话中/轮到你/已暂停）、回答提示、教练描述 | P0 |
| P-03 | 对话文字实时展示（语音实时转写，AI 回复流式输出） | P0 |
| P-04 | 操作：开始、暂停、继续、停止、回放、设置 | P0 |
| P-05 | 默认语音输入（按住说话 / 自动断句两种），支持切换文本输入 | P0 |
| P-06 | 计时器，达到时长上限自动结束 | P1 |
| P-07 | 网络中断自动暂停并保存进度 | P1 |

状态机：
```text
未开始 → 进行中(AI说话 ⇄ 用户说话) ⇄ 已暂停 → 已停止 → 评估生成中 → 评估完成
```

### 3.3 通话页面
| 编号 | 需求 | 优先级 |
|---|---|---|
| C-01 | 拨号盘（号码预置），拨号→振铃(2–4s)→接通 | P0 |
| C-02 | 通话中：计时、声波动画、可选实时字幕 | P0 |
| C-03 | 静音、暂停、继续、挂断、回放 | P0 |
| C-04 | AI 角色可按画像设定拒接/挂断（高难度场景） | P2 |

### 3.4 练后评估
| 编号 | 需求 | 优先级 |
|---|---|---|
| E-01 | 综合得分（0–100）、评级（S/A/B/C/D）、与上次对比 | P0 |
| E-02 | 阶段评估：开场破冰、需求挖掘、方案呈现、异议处理、促成成交，各自打分 | P0 |
| E-03 | 维度评估（雷达图）：沟通表达、需求洞察、产品讲解、异议处理、成交推进、情绪管理 | P0 |
| E-04 | 状态指标：语速、填充词次数、发言占比、停顿、情绪倾向 | P0 |
| E-05 | 关键片段点评：原话、问题、推荐说法，可点击回放该片段 | P0 |
| E-06 | 改进建议及推荐专项训练场景 | P1 |
| E-07 | 评估生成时间 ≤15 秒，期间显示进度 | P1 |

评级规则：S ≥90，A 80–89，B 70–79，C 60–69，D <60。
综合得分 = Σ(维度得分 × 场景配置权重)，权重和为 100%。

### 3.5 看板（能力仪表盘）
| 编号 | 需求 | 优先级 |
|---|---|---|
| D-01 | 概览：能力总分、本周练习次数、累计时长、连续天数 | P0 |
| D-02 | 六维雷达（本期 vs 上期，周期可选 7/30/90 天） | P0 |
| D-03 | 成长曲线（得分趋势） | P0 |
| D-04 | 专项能力卡片，最低两项标记“短板” | P0 |
| D-05 | 专项训练入口，推荐 3 个对应场景并可直接进入 | P0 |
| D-06 | 场景类别平均分柱状图 | P1 |

维度得分 = 近期 N 次会话该维度得分的加权平均（近期权重更高），无数据显示“待评估”。

### 3.6 我的 / 练习记录
| 编号 | 需求 | 优先级 |
|---|---|---|
| M-01 | 个人信息头部：头像、昵称、等级、总练习次数 | P0 |
| M-02 | 练习记录列表：场景、类别、日期、时长、得分、模式 | P0 |
| M-03 | 记录筛选（类别/时间/分数）与排序 | P1 |
| M-04 | 进入评估详情、回放录音、再练一次 | P0 |
| M-05 | 删除记录 | P2 |

### 3.7 场景构建及修改
| 编号 | 需求 | 优先级 |
|---|---|---|
| B-01 | 基础信息：名称(≤30字)、类别、封面（上传/AI 生成）、描述(≤200字)、难度1–5 | P0 |
| B-02 | 目标：练习目标、成功标准、评估维度及权重 | P0 |
| B-03 | 角色画像：姓名、职位、公司、性格、态度、痛点、常见异议、隐藏信息 | P0 |
| B-04 | 参数：语速 0.8–1.5x（步长 0.1）、音色、开场方（AI/用户）、时长上限 3–30 分钟、提示强度（关/弱/强） | P0 |
| B-05 | 实时卡片预览、试练、保存草稿、发布 | P0 |
| B-06 | 我的场景列表：编辑、复制、删除；系统场景只能复制后修改 | P1 |

| S-01 | 手机号验证码、邮箱密码登录注册；忘记密码 | P0 |
| S-02 | 首次登录引导：岗位、行业、目标能力 | P1 |
| S-03 | 设置：默认输入方式、麦克风测试、默认语速、提示/教练开关、通知、隐私 | P1 |

## 4. 数据模型（核心）
| 实体 | 关键字段 |
|---|---|
| User | id, 昵称, 头像, 岗位, 行业, 等级, 创建时间 |
| Scenario | id, 名称, 类别, 封面, 描述, 难度, 目标, 成功标准, 维度权重, 角色画像(JSON), 语速, 音色, 开场方, 时长上限, 提示强度, 创建者, 状态(草稿/发布) |
| Session | id, 用户, 场景, 模式(对话/通话), 开始/结束时间, 时长, 状态, 录音地址 |
| Message | id, 会话, 发言方, 文本, 音频片段, 时间戳 |
| Evaluation | id, 会话, 综合分, 评级, 阶段分(JSON), 维度分(JSON), 状态指标(JSON), 片段点评(JSON), 建议 |
| AbilitySnapshot | 用户, 日期, 各维度分 |

## 5. 非功能需求
- 性能：首页首屏 ≤2s；AI 首句响应 ≤1.5s；语音转写延迟 ≤500ms。
- 兼容：Chrome/Edge/Safari 最新两个版本，iOS 15+、Android 10+ 浏览器。
- 权限：首次练习请求麦克风权限，拒绝时自动切换文本输入并提示。
- 安全隐私：录音与对话仅本人可见，支持删除；传输全程 HTTPS。
- 可访问性：文字对比度 ≥4.5:1，所有图标按钮带文字标签。

## 6. 空状态与异常
| 场景 | 处理 |
|---|---|
| 无推荐数据 | 展示热门场景 + 引导完善岗位信息 |
| 无练习记录 | 插画 + “去练第一个场景”按钮 |
| 看板无数据 | 显示“完成 1 次练习后解锁能力分析” |
| 麦克风不可用 | 提示并切换文本输入 |
| 评估失败 | 保留对话记录，提供“重新生成评估” |
