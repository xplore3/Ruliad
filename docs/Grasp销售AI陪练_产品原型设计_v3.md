# 销售 AI 陪练｜PC/手机自适应产品原型设计 v3

> 本文档是设计与开发交付规格。所有人物、对话、分数、练习次数均为虚构演示数据；角色照片由 AI 生成。产品名"Grasp"为设计暂名。本版本(v3)取代 v2 的手机优先方向：**PC 与手机双端自适应、浅色背景、小红书式图文卡片信息流、珊瑚红主色**。配套 HTML 原型位于 `docs/prototype-v3/`，双端截图位于 `docs/_prototype_v3_assets/`。

## 1. 设计方向

**一句话**：像刷小红书一样发现销售练习场景，像打真实电话一样开口练习，练完拿到一份可执行的能力报告。

- **借鉴小红书**：浅色背景、圆角图文卡片瀑布流、底部 Tab、轻松的浏览感。场景以"图文笔记"的形式被发现和点击进入。
- **区别于小红书**：不做社交关注/点赞社区；卡片信息流服务于"训练"目标——每张卡片强化**场景类别标签**（电话销售 / 客户主动咨询 / 成交谈判 / 地推破冰）、**练习状态**（已练习 + 得分）、**难度与预计时长**；数据组件（雷达图、评分环、趋势线）是界面的一等公民。
- **主色**：珊瑚红 Coral `#FF6B5B`。比小红书红 `#FF2442` 更暖、更柔和，传递"陪练教练"而非"内容社区"的气质。

## 2. 设计令牌（Design Tokens）

> v3.1 起追加「高级感执行细则」：UI 壳层去彩色化（彩色只留给内容与珊瑚红主操作）、emoji 不进导航与标题（导航图标用 CSS mask 线性 SVG）、阴影用双层极浅而非发光、标题负字距 + 数字等宽（`tabular-nums`）、封面叠细网格纹理。详见 §2.1。

| `--coral-soft` | `#FFF0EE` | 选中底色、强调区块背景、徽章底 |
| `--bg` | `#F7F7F8` | 页面背景（浅色） |
| `--card` | `#FFFFFF` | 卡片、面板 |
| `--text` | `#1F2329` | 主文字 |
| `--text-2` | `#6B7280` | 次级文字、说明 |
| `--line` | `#EBEBEF` | 分隔线、卡片描边 |
| `--green` | `#2FAE7B` | 成功、已完成、优秀分数 |

类别色（场景标签）：电话销售 `--coral`、客户主动咨询 `--blue`、成交谈判 `--amber`、地推破冰 `--green`——类别用"彩色细标签"呈现，珊瑚红仍独占主操作。

### 2.1 高级感执行细则（v3.1）

不改色系，靠执行细节拉开档次：

1. **颜色降噪**：筛选条、类别标签等壳层元素用中性灰底 `#F1F2F4` + 6px 类别色小圆点（`.cdot`）作信号；彩色 soft 底只留给状态徽章（分数、进行中）。界面 90% 黑白灰，颜色让给卡片封面与珊瑚红。
2. **图标统一**：导航与系统图标一律 CSS mask 单色 SVG（随文字色，激活变珊瑚红），禁止 emoji 进导航/标题；emoji 只允许出现在内容区（对话、徽章等拟物语义处），并收敛尺寸。
3. **阴影纪律**：卡片 `0 1px 2px + 0 10px 30px -14px` 双层极浅阴影；主按钮无静止阴影，hover 上浮 1px 才出现短阴影；删除一切彩色发光。
4. **字体层级**：标题 `letter-spacing:-.01/-.02em`、大数字 800 字重 + `tabular-nums`；章节标题用 4px 珊瑚红竖条代替 emoji 前缀。
5. **激活态克制**：PC 菜单激活 = 加粗 + 底部 16px 珊瑚红短线（非色块胶囊）；Tab 激活 = 图标文字变珊瑚红。
6. **质感细节**：卡片封面叠 22px 细网格纹理、头像加 2.5px 白描边与定向投影；hover 卡片上浮 4px + 阴影加深，200ms ease-out。
7. **角色形象真实化（v3.2）**：卡片封面与头像不再使用"圆底+姓氏大字"占位，改用 AI 生成的角色形象照（`assets/avatars/man-1~4.jpg / woman-1~4.jpg`）。封面照片通栏铺满、按 t1–t4 类做高低错落形成瀑布流节奏；`object-position:center 20%` 裁掉底部水印区域；底部 44px 渐隐蒙层保证徽章可读。圆形头像内嵌同一照片（`object-fit:cover`）。真实产品上线时角色照由画像生成服务产出，原型仅作演示。

## 3. 响应式策略

| 断点 | 宽度 | 导航形态 | 内容布局 |
|---|---|---|---|
| 手机 | ≤768px | 底部固定 4 Tab（首页/构建/看板/我的）+ 顶部轻量标题栏 | 单列，卡片瀑布流 2 列，全屏练习/通话 |
| 平板 | 769–1200px | 顶部菜单居中 | 内容最大宽 960px，卡片 3 列 |
| PC | ≥1201px | 顶部固定菜单栏（Logo + 4 菜单 + 头像） | 内容最大宽 1200px 居中，卡片 4 列 |

- 同一套 HTML 用 CSS 媒体查询自适应，无独立移动站；手机底部 Tab 在 PC 上隐藏，PC 顶部菜单在手机上折叠为标题栏。
- 手机底部 Tab 与输入区避让安全区（`safe-area-inset`）；练习页/通话页在手机为全屏沉浸布局，在 PC 上为居中大卡片 + 右侧信息栏。
- 二级页面（练习、评估、构建编辑）手机端隐藏底部 Tab、顶部显示返回；PC 端保留菜单、以面包屑/返回按钮回退。

## 4. 导航与信息架构

```
PC 顶部菜单 = 手机底部 Tab：首页 · 构建 · 看板 · 我的

首页（场景列表）
  ├─ 场景卡片 → 场景详情/练习页 → 练后评估 → 返回（卡片标记"已练习+分数"）
  └─ 搜索 / 类别筛选（电话销售·客户主动咨询·成交谈判·地推破冰）
构建
  ├─ 我的场景列表 → 编辑场景（目标/角色画像/语速/难度）
  └─ 新建场景（模板 → 配置 → 预览 → 保存）
看板（能力仪表盘）
  ├─ 多维能力雷达 + 维度明细 → 专项训练 → 推荐场景（跳首页对应卡片）
  └─ 趋势 / 练习热力
我的
  ├─ 练习记录 → 历史评估报告
  ├─ 设置（账号、通知、语音、隐私）
  └─ 关于
未登录：登录/注册（手机号验证码 / 密码 / 第三方）
```

## 5. 页面详细设计

### 5.1 首页（场景列表）

- **顶部**：PC 为菜单栏 + 搜索框 + 类别胶囊筛选条；手机为标题栏 + 搜索 + 横向滑动类别胶囊。
- **推荐区**：顶部一条"为你推荐"横向横幅（PC）/ 全宽卡片（手机）：基于最近弱项维度推荐 1 个场景，主按钮"立即开练"。
- **卡片瀑布流**：PC 4 列 / 平板 3 列 / 手机 2 列。每张卡片：
  - 封面区：角色 AI 头像大图 + 左上**类别标签**（彩色细胶囊）+ 右上难度（初级/进阶/挑战）。
  - 文字区：场景标题（如"向谨慎的采购总监报价"）、1–2 行描述、角色名与职位、预计时长。
  - 底部：人物标签（如"谨慎 · 重数据 · 压价"）。
  - **已练习卡片**：封面右上叠加珊瑚红"已练习 82分"徽章，卡片底部出现"再练一次"文字链。
- **空/加载态**：骨架卡片；筛选无结果显示插画 + "换个类别试试"。

### 5.2 练习页面（参考 Yoodli 对话练习页）

进入方式：首页卡片 → 详情 →"开始练习"。

- **布局**：PC 三栏——左：参与者列表；中：对话区 + 提示屏；右：目标与实时提示。手机单列：顶部参与者横条、中间对话、底部操作。
- **参与者展示模块**：我方（用户头像 + "你"）、对方（AI 角色头像、姓名、职位、性格标签）、可选教练/陪练观察者角标。
- **提示画面屏**（对话区顶部的状态条）：
  - "对方正在思考…"（三点动画）
  - "轮到你说话了"（珊瑚红呼吸高亮 + 麦克风动效）
  - 教练提示："试着先确认对方的预算范围"（可收起）
  - 陪练者描述条：当前角色状态，如"对方态度：谨慎，对价格敏感"
- **对话文字展示**：气泡式双向转写，我方右侧珊瑚红气泡、对方左侧白气泡；语音轮次附播放键与转写校对入口。
- **操作区**：开始 / 暂停 / 继续 / 停止（结束）/ 回放 / 设置（语速、提示强度、字幕开关）。
- **输入**：默认语音输入——大麦克风按钮（手机底部居中，PC 对话区下方居中），按住或点击说话、实时转写；支持切换文本输入（输入框 + 发送）。
- **异常态**：未授权麦克风→引导授权或切文字；断网→停止发送并保留已确认轮次；转写失败→重录/切文字。

### 5.3 通话页面（仿电话语音通话）

- **手机**：全屏深色免打扰通话界面（此为深色特例：模拟真实来电沉浸感，仍用珊瑚红点缀）；顶部角色头像大圆 + 姓名 + 职位 + 通话计时 + 实时字幕条。
- **PC**：居中通话卡片（480px）+ 右侧场景目标/提示侧栏。
- **拨号态**：进入时显示"正在呼叫 王总…"拨号动画（声波扩散），3 秒接通。
- **通话中控件**：静音、扬声器、键盘（拨号盘可选）、字幕开关、**暂停**（对方挂起："通话已保持"）、**继续**、**挂断**（珊瑚红圆形大按钮）。
- **回放**：挂断后进入回放页——按轮次列出音频 + 转写，点击任意轮次播放。
- 挂断确认 → 生成评估报告（异步，可离开）。

### 5.4 练后评估

报告分**多阶段 × 多维度**：

- **总分头部**：大号评分环（0–100，珊瑚红渐变描边）+ 一句话总评 + 与上次对比箭头。
- **阶段拆解**（多过程）：开场破冰 / 需求挖掘 / 价值呈现 / 异议处理 / 推进成交——每阶段一行：阶段得分、关键证据引用（点击定位对话轮次）、AI 点评。
- **状态维度**：情绪稳定性、语速（实测 WPM 与目标对比）、停顿与填充词次数、倾听占比。
- **表现维度**：六维雷达图（需求挖掘/价值表达/异议处理/推进成交/倾听共情/表达清晰）+ 可读数值列表，每维附"改进动作"。
- **下一步**：薄弱维度 → "针对性再练"按钮 → 推荐场景卡片；可"查看完整回放"、"分享报告"。
- 证据不足的维度标"证据不足"，不给武断 0 分；语音指标在纯文字模式下标"未评估"。

### 5.5 能力仪表盘 / 个人能力看板

- **顶部总览**：综合能力分 + 本周练习次数/时长 + 连续天数。
- **多维能力分析**：六维雷达图 + 维度列表（分数、30 天趋势迷你折线、状态色）。
- **专项能力训练**：点击任一维度 → 维度详情页（历史趋势、薄弱点诊断）→ **推荐场景列表**（该维度对应类别的卡片），一键进入练习。
- **练习热力**：近 12 周热力格子图。
- **成长里程碑**：徽章墙（首练、连续 7 天、异议处理突破 80 分等）。
- 文字与语音维度分开标注，不混合排名。

### 5.6 练习记录（我的 Tab 内）

- 列表项：角色头像、场景标题、类别标签、时间、模式（文字/语音/通话）、得分（色阶：≥85 绿 / 60–84 琥珀 / <60 珊瑚红）。
- 筛选：全部 / 本周 / 本月；按模式、类别过滤；搜索。
- 点击 → 该次练后评估报告；右滑/长按可删除。
- 空态：插画 + "从首页挑一个场景开始第一次练习"。

### 5.7 场景构建及修改

- **入口**：构建 Tab = 我的场景列表（卡片同首页样式 + "编辑/复制/删除"）+ 大号"新建场景"按钮。
- **编辑器分节表单**（PC 左导航右表单；手机分步/分组折叠）：
  1. **场景基础**：标题、类别（四类单选）、描述、封面头像（AI 生成/上传）、难度、预计时长。
  2. **练习目标**：我方目标（如"拿下二次面谈"）、成功标准、禁止事项。
  3. **角色画像**：姓名、职位、行业、性格标签、决策风格、典型异议、背景故事、禁止透露内容。
  4. **对话参数**：语速滑杆（慢/标准/快 + WPM 参考值）、挑战强度、打断频率、方言/口音（可选）。
  5. **评估配置**：选用评分维度与权重（默认模板，可进阶编辑）。
- **预览试跑**：保存前可"试聊三轮"预览角色语气；保存生成新版本，历史练习绑定旧版本。
- 修改公开模板场景 → 自动保存为"我的派生场景"，不改写公共模板。

### 5.8 设置 / 关于

- 设置分组：账号与安全（手机号、改密）、通知（练习提醒、报告生成通知）、语音与练习（默认模式、语速默认、提示强度）、隐私（录音授权、数据导出、注销）、通用（主题跟随系统、清除缓存）。
- 关于：版本号、产品介绍、用户协议、隐私政策、联系客服。
- 手机为列表页；PC 为左菜单右内容双栏。

### 5.9 登录 / 注册

- 浅色居中卡片（PC 480px 居中；手机全屏）。Logo + 一句话价值主张。
- 手机号 + 验证码（主路径）；密码登录切换；第三方（微信/Apple）占位。
- 协议勾选（用户协议/隐私政策），未勾选禁提交；首次登录进入兴趣类别选择（四类多选）用于首页推荐冷启动。

## 6. 组件清单

导航（PC 菜单栏 / 手机 Tab 栏）、场景卡片（含已练习态）、类别胶囊、搜索框、评分环、六维雷达图、趋势迷你折线、热力格子、聊天气泡、提示状态条（思考中/轮到你了/教练提示）、语音波形、大麦克风按钮、通话控制圆钮、表单分组、滑杆、步进器、开关、徽章、空态插画、骨架屏、Toast。

## 7. 关键状态与边界

- 加载：卡片骨架屏；报告生成异步（可离开，完成后通知）。
- 空态：无练习记录、无自建场景、筛选无结果、能力数据不足（练满 3 次解锁雷达图）。
- 异常：麦克风未授权、断网重连、转写失败、报告生成失败可重试，不伪造数据。
- 一致性：同一用户同一维度的分数在评估报告、看板、记录列表中口径一致；规则/难度不同不直接比较。

## 8. 与 v2 的关系

v2 为手机优先、深色炭灰、探探式滑卡；v3 改为 PC/手机自适应、浅色、小红书式卡片信息流与珊瑚红主色，菜单收敛为 首页/构建/看板/我的 四入口。v2 中关于评分证据链、角色画像版本化、隐私合规的约束（引用定位、版本绑定、授权与去标识）在 v3 继续有效，见 §5.4 / §5.7。
